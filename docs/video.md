# Video capability status

The browser capability report records an observed Gemini browser video
generation/playback result (1280×720 MP4, approximately ten seconds) for a
tested account. That observation is not a recoverable, supported MCP generation
workflow. No generation job, status polling, cancellation, authenticated
artifact retrieval, or end-to-end ChatGPT playback tool is registered.

The project includes bounded media validation/private artifact infrastructure
and a `video-result-v1.html` player resource. Those components alone do not
provide a generated video or secure client delivery. `gemini_video_capabilities`
reports the current boundaries; consult it at runtime. Do not create a fake
job or infer user entitlement. See [feature matrix](feature-matrix.md).
